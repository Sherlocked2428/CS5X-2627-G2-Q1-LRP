Parts of a recursion


        
A recursion is a function that is defined in terms of itself, i.e., it calls itself at some time in its execution. For instance, in the previous example, the seq function calls itself when extracting the previous term. A recursion has four parts:
        
    
            
  • the base case/s, the condition/s where the function does not call itself (and thus stops the function from going in an infinite loop);
    • 
            
  • the base definition, the value of the function (which must not call itself) at the base case/s;
    • 
            
  • the recursive case/s, the condition/s where the function calls itself; and
    • 
            
  • the recursive definition, the value of the function (which must call itself) at the recursive case/s.
    • 
        


        
So, for our sequence, we can define it by writing it as a piecewise-defined function, then determining the parts from there. (We use this notation because it is visually easier to understand.) In our definition below, the base case is colored $\textcolor{red}{\text{red}}$, the base definition is colored $\textcolor{orange}{\text{orange}}$, the recursive case is colored $\textcolor{lightgreen}{\text{green}}$, and the recursive definition is colored $\textcolor{lightblue}{\text{blue}}$.
        
        \[a_n=\begin{cases}\textcolor{orange}{1}&\textcolor{red}{\text{if $n=0$}}\\\textcolor{lightblue}{2a_{n-1}+n}&\textcolor{lightgreen}{\text{if $n>0$ and $n$ is an integer}}\end{cases}.\]

            Solution to Example 2
            
            
Let's number the boxes according to size, with the largest being the $0$th box, the second largest being the $1$st box, and so on, and let $s(n)$ be the size of the $n$th box. Suppose the $0$th box has size $S$. Then, our base case is $n=0$, and our base definition is $s(n)=S$.


            
Now, since the size of each box is a constant multiplied to the size of the previous box, we have that $s(n)=c\cdot s(n-1)$ for some constant $c$ when $n$ is a integer greater than zero. So, our recursive case is $n>0$ and $n$ is an integer, and our recursive definition is $s(n)=c\cdot s(n-1)$.

Memoization


        
Okay, recursion is a great method of doing things, but it has one fundamental flaw. Try running this program, which contains our seq function from earlier:


         
        

        
 
        

 
         
        

        

        

        
We end up getting a RecursionError that says Maximum call stack size exceeded. Why is that? Well, whenever our function calls itself, it adds another layer to what is called the call stack, which contains the function calls that are in progress, so that the currently running function can use it. However, the number of layers has a limit, so once this limit is reached, a stack overflow occurs, and the recursion cannot be completed. This is pretty bad, since this means that we cannot use our seq function to calculate large terms (our web interpreter breaks down starting with seq(8193)).
