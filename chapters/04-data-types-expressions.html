Data Types

Characters (char) and Strings (str)

Strings are sequences of characters that can be used to represent text. To make string literals, you can enclose a character sequence in either single quotes ('') or double quotes (""). Individual character literals can be made by enclosing a single character in single quotes ('').

Escape Sequences are like inline commands that allow characters to ‘escape’ their original meaning and perform new functions. An example for this is '\n', which is commonly used when you want to start a new line in your string.

Integers (int)

Integers are, well, integers. They are data with infinite precision, can either be positive or negative, but do not have decimal places. E.g. 1, -2, 3

Floating-Point Numbers (float)

Contrary to ints, float values can have decimal places. Like ints, they can also have positive or negative values. E.g. 1.0, -2.0, 3.0

Boolean (bool)

Boolean values can either be True or False. Also, it is actually a type of ints, where False is also representative of the int value 0, whilst True represents the int value 1. Later, we will also see that when a comparison expression is evaluated, the compiler outputs either True or False.

Lists

Lists are collections of data that are ordered, changeable, and allow duplicate values. Its elements can be referenced in the form ‘listName[index]’, where listName is the name of your list, and index is the element’s index. The indices for lists, (and for most other collections) start at 0 for the first element starting from the right, with the last element having an index one less than the list’s length (n-1).

Tuples

Tuples are collections of data ordered and allow duplicate values. Unlike lists, a tuple’s elements are unchangeable; they cannot be modified, added to, or removed.

Sets

Sets are collections of data unordered, unchangeable, and don’t allow duplicate values. They are similar to the sets we see in math

Dictionaries (dicts)

Dictionaries are collections of data that are stored in key:value pairs. They are unordered, changeable, and allow duplicate values BUT not duplicate keys.

Range (range())

Range is a special kind of data type that represents an unchanging sequence of numbers. They can be instantiated similar to a function: range(start, stop, step). ‘start’ represents the first value of the sequence and from which the following numbers will be generated. ‘Step’ represents the value you iteratively add to the current value – starting from the ‘start’ value – to get the next number, which stops when the value is exactly on or beyond the ‘stop’ value. Additionally, range can also be instantiated with only the ‘start’ and ‘stop’ values, with the step being set to a default value of 1.

Operators

Arithmetic Operators (+ - * / // %)

The arithmetic operators are: + - * / // %, which represent addition, subtraction, multiplication, division, and modulo separately.

Comparison Operators (== != < > <= >=)

The comparison operators are used to compare two values, and outputs either True or False. The comparison operators are: == != < > <= >=, representing ‘is equal to’, ‘is not equal to’, ‘is less than’, ‘is greater than’, ‘is less than or equal to’, and ‘is greater than or equal to’, respectively.

Logical Operators (and, or, not)

The logical operators compare boolean values and output another boolean value. The logical operators are: and, or, not. and will output True if both values are True, and False if otherwise. or will output True if at least one value is True, and False if both are False. not negates the boolean; it outputs True if the boolean is False, and vice versa.

Identity Operators (is, is not)

Identity operators check if two values point to the same object in memory. is outputs True if they are the same, False if not. is not simply the negation of is.

Membership Operators (in, not in)

Membership Operators check if a value or collection of values can be found within another collection of values. in outputs True if the value to its left is found in the value to its right, and False if otherwise. not in is simply a negation of in.
