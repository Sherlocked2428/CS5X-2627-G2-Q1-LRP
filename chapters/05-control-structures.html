Introduction: Kinds of control structures

        

        
Sequential

        

            
Sequential control structures execute statements in a linear fashion, one after another.

        

        

        
        
        

        
 
        

 
         
        

        

        

        

        
Conditional

        

            
Conditional control structures execute different statements based on whether a condition is true or false.

        

        

        
        
        

        
 
        

 
         
        

        

        

        
But wait! Not all conditional control structures are if-else statements. If-else if statements are a more complex forms conditional control structures.

        
In Python, else if is written as elif.


        
        

        
 
        

 
         
        

        

        

        

        
Iterative

        

            
Iterative control structures execute statements repeatedly until a certain condition is met.

            
There are two types of iterative control structures in terms of logic: pre-tests and post-tests.

            
Iterative control structures are often executed with for and while loops.
