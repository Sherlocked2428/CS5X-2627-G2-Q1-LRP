Software Development Life Cycle

Written by Byron Mikhail Bautista

There are 5 Main Stages in the life cycle of program development, specifically:

  • Problem Definition
  • Logic Formulation
  • Coding
  • Testing and Debugging
  • Storage and Maintenance

    • Problem Definition

    The first stage in software development is the aptly named problem definitionb>. This is where most developer identify a problem that they aim to solve with their program. In short, this is why a program gets made, while not yet how it gets made. Moreover, there are also 4 sub-parts within this stage, being the:

  • Output: The desired outcome or result the program should produce
  • Given: The values or conditions present in environment that are known to be true. For example, gravity = 9.8m/s^2
  • Input: The things (information and data) introduced to system
  • Restriction: The limitations on what input cannot be. For instance, a calculator-esque program should only be able to accept numerical inputs.

    • Logic Formulation

    This is where a developer can outline how their program works and how to address the problem defined in the last stage. This stage can include the creation of flowcharts, algorithms, or any other form of preemptive planning.


    Coding

    This stage is where the initial code gets made. The developer takes the outline created in the last stage and translates it into an actual programming language, such as Java, Python, or C++, and creates a first-draft program. In essence, coding is where a software goes from planned logic to an executable softwareb.


    Testing and Debugging

    Going hand-in-hand with the coding stage, this is where the said program receives edits. Testing refers to running the code, evaluating it, and finding any potential errors, while debugging mainly is the act of editing the errors and making the program flow smoother. Often this stage is the most repeated, as fixing one error could potentially reveal another, and repeated until program behaves as expected.


    Storage and Maintenance

    This is the stage where the completed program other necessary files are stored and managed for future use. This allows developers and users to access the software and its files when they are needed, while also helping prevent important data or code from being lost. Maintenance includes the upkeep of the software, making sure it gets updated so it remains in use.


    Note

    While the software development life cycle is called a cycle, development is not hindered by a strict flow. It can jump from any stage to any stage, whenever and wherever a developer sees fit. For example, a developer can go from defining a problem to immediately coding a program, and they can even go back, which can be seen late during the cycle if a significant change happens forcing the developer to go from testing and debugging a program all the way back to redefining a problem. There is one main exception to this, wherein you cannot go from Problem Definition to Storage & Maintenance.
