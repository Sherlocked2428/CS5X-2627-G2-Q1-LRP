Python

Python is a high-level, interpreted, dynamically typed, and free and open-source programming language. It was designed to make programs relatively easier to use, read, and write with, allowing developers to focus on creating programs instead of dealing with low-level languages.

With Python, instead of having to specify variables yourself, it is labeled automatically. For example, instead of having to label the variable x as an integer, if you write it as x = 10, it will automatically be labeled as an integer by Python.

High-level languages such as Python are languages easily understood by people, running on multiple systems, whilst low-level uses binary.

Python runs code line-by-line instead of needing “breaks” or a separate compilation step

It is a free and open source language, meaning it can be used without purchasing a license, and its source code is available for people to study, modify, and distribute according to its license.


Why was Python created?

Conceived in the late 80's, Guido van Rossum from the Netherlands created Python as a project during his Christmas holidays.

Inspired by other languages, Guido set out to improve them by fixing its limitations, and create a language that allows users to write with less lines and to focus on code readability.

Unlike what most people think, Python was not named after the snake, but rather the BBC comedy series titled Monty Python's Flying Circus. Python was officially first released in 1991.

Van Rossum led the direction of Python, where he was called the Benevolent Dictator for Life from its inception all the way until July 12, 2018.


Where is Python used?

Python is mainly used for web development, scripting, and software testing.

The language can be used for creating websites, developing applications, and produce tools and scripts for various uses.

Python is relatively easy to use and understand, and it can be used by anyone, from beginners to experts, and for any use, whether it be for fun or for professional use.

Due to its straightforward and diverse use, as well as its large collection of libraries, it is used by multiple industries, and most of the top companies who use it are those like Google, Dropbox, and Quora.


How has Python evolved?

Since its inception, there have been 3 main major releases for Python, aptly named Python, Python 2.0, and Python 3.0.

Python was the original release, followed by Python 2.0 in October 16, 2000, and Python 3.0 in December 3, 2008.

Each version has specific usage that explains their release.

Python 2.0 was released on October 16, 2000, and it introduced several improvements. It was continued to be developed for nearly a decade until Python 3.0 was released. Python 3.0 was released on December 3, 2008.

It introduced so many significant changes that it was not compatible with Python 2.0. This meant that most Python 2.0-written programs needed to be modified to run correctly with Python 3.0.

On New Year's Day, 2020, Python 2.0 officially reached the end of its development life. This meant that Python 2.0 would no longer receive updates or fixes, making Python 3.0 the current standard version for modern Python development to this day.
