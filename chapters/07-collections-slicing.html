 📁 What is a collection?

    • 
                
  • And sized means that these collections have a length.

Mutability

        The mutability 
 of a collection indicates whether we can modify the collection or not. A list for example, 
        is mutable, (as we can see later on) we can add, modify, or remove items from the list. However, an immutable collection 
        means we can't add, modify, or remove items from the list. One example of this we will see later is a tuple.
        
Lists

        

             Lists 
            are collections that are ordered, mutable sequences. A list can be made up of data with different data types. One list can contain 
            int, float, and str. A list is defined by square brackets "[]" with elements separated by 
            a comma "," within the square brackets.
            


            For example, this is a list: myList = [12, 21, 35, "a", "b", 1.5]

Dictionaries

        

             Dictionaries 
            are collections composed of key-value pairs. They are written with curly brackets "{}", where the keys and values are 
            separated by a colon (:) and the pairs are separated by a comma (,). The keys and the values can be any data type and they can be 
            different across the pairs and the dictionary. Here's an example of a dictionary:
            numbers = {5: "odd", 6: "even", 72: "even", 11: "odd"}



            A dictionary is indexed by its keys. Keys can be numbers or strings, and they can also be tuples as long as they only contain
            strings, numbers, or tuples. The keys must be an immutable data type, and are not allowed to be mutable. For example: using this array of letters
            listA=["A","B","C","D","E","F"] as a key is not allowed.

Slicing Collections

In ordered sequences, we can easily access the data individually through their indices or keys in dictionaries. 
A string is an example of an ordered sequence. Let's take the string: myWord = "order". 


Indices

In this case, we can get its individual characters: myWord[0] would print "o", myWord[1] would print "r" and so on.
However, if we access something like myWord[200], this would return an IndexError. 

We can also provide a negative index, meaning it will start from the end of the list (the last item is -1, second to the last item is -2, and so on).
For example, myWord[-1]="r", myWord[-2]="e", and myWord[-3]="d". 




Slicing: Start and Stopping Endpoints

To get an entire subsection of data though rather than individual ones, we can use slicing. The format is like this:
myCollection[start:end], where start refers to the starting point (inclusive), while the end 
refers to the stopping point (non-inclusive). 

For example, getting myWord[2:4] would give us only myWord[2] and myWord[3] which is "de". 
However it is not required to provide these start and end parameters. There are three examples of this: 
myWord[0:] (when we omit the end), myWord[:2], when we omit the start, and myWord[:]
when we omit both the start and the end. 



When we omit the end, this means the slice will continue until the very end of the sequence (end inclusive). 
In this case, evaluating gives: myWord[0:]="order". When we omit the start, the slice will start from
the first element of the sequence until the specified stop (stop exclusive). In this case, evaluating gives: myWord[:2]="or". 
Finally, myWord[:] simply gives the whole list, having no start and stop parameters indicated.


Slicing: Step Argument 

Aside from the start and stop argument, the step argument is also indicated in slice notation like so:
[start:end:step]
For example, if we have the string exampleStr = "supercalifragilisticexpialidocious", and we want to get every other letter in this word,
from indices 0 to 12 (inclusive), we use this slice notation: [0:13:2]. The step index can also be negative, which returns a slice where
